# GESTAAC D1 Virtual Lab

A mobile-first virtual lab for the GESTAAC MCC course **Creating Digital Marketing Content** (leading to Digital Marketing Level III,
unit *Create content*). Trainees learn and practice on a phone or a PC: lessons from the e-CBLM, the **Content Planner** (client brief,
vision, SMART goals, audience, platforms, keywords, two-week content calendar), the **Post Composer** (graphic size check, caption with
counters and copywriting frameworks, proofreading checklist, live Facebook / Instagram / TikTok / Story previews, media log),
auto-checked activities and self-check quizzes. The trainer watches live progress, opens or closes activities, and grades the quality
of the work with the Performance Criteria Checklists.

- **Students:** open the link, sign in with the class code, student ID and PIN, then **Add to Home Screen**. The app works offline;
  your answers are sent when you are back online.
- **Trainer board:** add `#/trainer` to the link.
- **Lesson videos:** placeholders ("Video coming soon") until the recordings are added in `js/videos.js` or on the trainer board.

Built as a static site (no build step): `index.html`, `js/` (ES modules), `data/` (day content generated by
`D1-Digital-Marketing-Content/_build/lab_build.py`, answers stored only as salted hashes). The back end is a Google Apps Script web app
(kept outside this repo in `virtual-lab-backend/`), set in `js/config.js`; with no URL the lab runs in demo mode.

Based on the DAL3 Virtual Lab. Third-party: [HyperFormula](https://hyperformula.handsontable.com/) (GPL-v3, see
`vendor/HYPERFORMULA-LICENSE.txt`), [Chart.js](https://www.chartjs.org/) (MIT) and [ExcelJS](https://github.com/exceljs/exceljs) (MIT).
This project's code is released under the GPL-3.0 to match.
